# GitAssignment Project

## University Assignment: Git & GitHub Workflow & Software Testing
- **Student Name:** Srinivasula Sagar
- **Course:** Software Engineering & Quality Assurance
- **Project Purpose:** Practical demonstration of version control workflows, branching, merging, ignore rules, commit undoing, remote repository synchronization, and functional test case design.

## Features Covered
1. Initial repository setup and tracking (`index.html`, `about.html`)
2. Feature branching (`feature` branch) and fast-forward merging into `main`
3. Commit history visualization (`git log --oneline --graph --all`)
4. Exclusion rules via `.gitignore` (`*.log`, `temp/`)
5. Safe commit undo demonstration using `git reset`
6. GitHub remote synchronization and public repository hosting
7. Comprehensive functional test suite for Login System
